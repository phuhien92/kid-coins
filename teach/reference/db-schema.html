DB Schema Cheat Sheet

Keep this open while working on API routes or migrations. Source of truth: src/lib/schema.ts

Ownership Hierarchy

families
├── family_settings (1:1)
├── rewards (1:N)              ← shared by all kids!
├── activity_log (1:N)
└── kid_profiles (1:N)
    ├── characters (1:1)
    ├── streaks (1:1)
    ├── tasks (1:N)            ← per kid, not per family
    ├── goals (1:N)
    ├── badges (1:N)
    ├── task_completions (1:N)
    ├── coin_transactions (1:N)
    └── redemption_requests (1:N)
