Three rules that are non-negotiable:
1. Coin yellow = money signal only. Never decorative.
2. Green = kid. Purple = parent. Never cross-shell.
3. Cream on pages, cream-card on cards. Never swap.

Two-layer rule: Cards use ambient shadow (float). Buttons use stamp shadow (press). Never mix them on one element. Cards don't stamp; buttons don't float.

Border Weights

WhereWeight
Primary buttons (green/purple), cards3px solid ink
Chips, badges, secondary buttons, compact card2.5px solid ink
Ghost buttons, inputs2px solid ink

Never drop the ink border below 2px for "elegance." The chunky border IS the brand. Thinning it is exactly the cold-fintech move the brand rejects.

Interactive State Pattern

/* Green primary button — full pattern */
className="
  bg-green text-cream-card
  border-[3px] border-ink rounded-button
  shadow-stamp-green
  hover:bg-green-dk
  focus-visible:outline focus-visible:outline-[3px] focus-visible:outline-ink focus-visible:outline-offset-[3px]
  active:translate-y-1 active:shadow-[0_1px_0_var(--color-green-dk)]
  disabled:opacity-50 disabled:pointer-events-none
  transition-colors
"

Every interactive element needs all three: :hover, :focus-visible, :active. Focus ring uses outline, not box-shadow (so it doesn't fight the stamp shadow). Disabled = opacity-50 pointer-events-none.
