# Mission

**Who:** A new software engineer taking over active development on Earnie (kid-coins).

**Why I'm learning this:**
> I need to be productive on this codebase — able to build features, fix bugs, and make sound architectural decisions — without tribal knowledge gaps slowing me down.

**What success looks like:**
- I can trace any user action (tap a task, redeem a reward) end-to-end through the stack
- I can add a new page or component without breaking the design system
- I can explain the auth model, the coin ledger, and the approval flow to a colleague or auditor
- I know where to look when something is broken

**Lesson plan (≈ 30 min total):**

| # | Lesson | Win |
|---|--------|-----|
| 01 | [The Earnie Loop](lessons/01-the-earnie-loop.html) | Explain the product to anyone in 30 seconds |
| 02 | [Database Deep Dive](lessons/02-database-deep-dive.html) | Navigate schema.ts confidently |
| 03 | [Auth & Sessions](lessons/03-auth-and-sessions.html) | Explain the auth model to a security reviewer |
| 04 | [The Coin Flow](lessons/04-coin-flow.html) | Trace a coin from tap to ledger |
| 05 | [Frontend Architecture](lessons/05-frontend-architecture.html) | Add a page without breaking the system |
