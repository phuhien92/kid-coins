The Earnie Loop

🏆 Win: Explain Earnie to anyone in 30 seconds

What is Earnie?

Earnie is a gamified financial-literacy app for families. Kids complete chores and self-care tasks to earn virtual coins. They save toward goals or redeem coins for parent-approved rewards. An AI coach helps parents shape those goals.

That's the whole thing. Everything in the codebase is in service of that loop.

The 30-second pitch: "Earnie turns everyday chores into a game. Kids earn coins for making their bed or reading — then spend them on real rewards like screen time or a toy. Parents approve everything, so it teaches both responsibility and money skills."

Two Audiences, One Product

Earnie has two distinct users who share a single app but live in completely separate shells:

🧒 Kids (ages 5–12)

  • Primary audience — the players
  • Short sessions: morning, after school, bedtime
  • They tap tasks done, watch coins grow, save toward goals
  • Can't read long sentences — needs big buttons, clear numbers
  • Live at /kid/* routes
  • CTA color: Green

👨‍👩‍👧 Parents (secondary)

  • The gatekeepers — they approve everything
  • Use it between other things, coffee in hand
  • Set tasks, approve redemptions, shape goals with AI
  • Need speed and clarity, not playfulness
  • Live at /parent/* routes
  • CTA color: Purple

Key rule: Green owns kid actions. Purple owns parent actions. A green button in the parent dashboard is a bug, not a design choice.

The Core Gamification Loop

Every feature in this app either drives or supports this loop:

Kid taps "Mark Done"
→
Parent approves
→
Coins credited
→
Goal / Reward

Supporting systems

  • Streaks — daily completion chains, shown as a 🔥 badge
  • Goals — a target coin amount with a progress bar ("Save 200 coins for a Switch game")
  • Characters — a customizable mascot (Penny/Lumi) kept in Character Studio
  • AI Coach — parent-facing, helps set realistic goals via /api/ai/coach
  • Activity log — append-only event stream powering the parent dashboard feed

Brand: Playful · Warm · Trustworthy

Understanding brand saves you from design regressions that are easy to introduce when you're focused on logic.

What Earnie IS

  • Cream paper background, ink linework borders — feels like a picture book
  • Fredoka (display) + Nunito (body) — rounded but not cartoonish
  • Coin yellow #F4D34E reserved for money signal only
  • Stamp-press shadow on every primary button — taps feel physical

What Earnie is NOT (anti-references)

  • ❌ No gradient slime, neon rainbows, or Comic Sans
  • ❌ No navy-and-gold fintech aesthetic
  • ❌ No "BUY NOW" energy, exclamation marks on every sentence
  • ❌ No gray-on-gray sterile SaaS

The Coin-Yellow Rarity Rule: #F4D34E must only appear on coin balance, progress bars, streak badges, and confetti. Never as decoration. Its rarity is what makes earning feel special.

🧠 Retrieval Check

1. A product manager asks you to add a green "Quick Add Task" button to the parent home screen. What do you say?

Reveal answer
Push back. Green owns the kid shell; purple owns the parent shell. The correct CTA would use bg-purple + box-shadow: 0 4px 0 var(--purple-dk). A green button in the parent dashboard is a design bug per the Two-Hue Authority Rule.

2. What's the purpose of the Activity Log table? Who reads it and when?

Reveal answer
It's an append-only event stream that powers the parent dashboard activity feed. Every meaningful action (task completed/approved/denied, reward redeemed/approved, coins adjusted, kid added) writes a row. Parents see it in real time on /parent/home. It's never updated — only appended to.

3. Coin yellow (#F4D34E) appears on a marketing banner card background. Is this OK?

Reveal answer
No. The Coin-Yellow Rarity Rule reserves #F4D34E strictly for money signal: coin pip, balance display, progress bar fill, streak badge, celebration confetti. Using it as decoration dilutes the meaning of earning — the moment a kid sees yellow, they should think "money", not "pretty".
