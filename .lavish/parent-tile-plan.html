Implementation steps
1

Add parentPin field to families schema & migration

Add parentPin: varchar(60) (bcrypt hash, nullable) to the families table in the schema. Generate and apply a migration. Add a POST /api/parent/verify-pin route (mirrors /api/kids/[id]/verify-pin) that bcrypt-compares against the stored hash and returns 200/401.

src/lib/schema.ts src/app/api/parent/verify-pin/route.ts
2

Create animated CoinFaceAvatar component

A client component rendering a gold SVG coin with eyes, smile, and mustache, with a gentle bob CSS animation. Eyes blink every ~3 s. Accepts size prop ("picker" = 52 px). Keep it self-contained with animation styles inline so it works anywhere.

src/components/shared/CoinFaceAvatar.tsx
3

Create ParentPickerTile component (button + PIN modal)

A <button> styled like a kid tile (purple tint tokens: bg-purple-tint border-purple-dk). On click it opens the existing Modal with a 4-digit numpad — same UI as the kid PIN modal but calling /api/parent/verify-pin. On success, router.push("/parent/home"). Use CoinFaceAvatar in the avatar slot.

src/components/shared/ProfilePickerTile.tsx
4

Render parent tile first; kid tiles tap straight in; remove footer link

In ProfilePickerPage: (a) put <ParentPickerTile /> first in the grid; (b) change kid tile onClick to navigate directly to /kid/home (remove the selectedKid state and PinModal entirely — kids no longer need a PIN to enter); (c) delete the <Link href="/parent/home">Parent dashboard →</Link> footer line. Keep ParentSignOutButton.

src/app/(auth)/profile-picker/page.tsx
5

Tests

Unit-test CoinFaceAvatar (renders, has accessible label). Test ParentPickerTile: clicking opens the PIN modal; successful verify navigates to /parent/home; wrong PIN shows error. Test /api/parent/verify-pin: correct hash → 200, wrong → 401.

src/components/shared/CoinFaceAvatar.test.tsx src/components/shared/ProfilePickerTile.test.tsx src/app/api/parent/verify-pin/route.test.ts
Parent PIN setup: The parent will need to set a PIN the first time (e.g. in Parent Settings). If no PIN is set yet, the tile click could skip the modal and go directly to /parent/home — or prompt them to set one. Decide before implementing step 3.
