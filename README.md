# kid-coins

Kid Coins is a playful “Earn & Learn” web app concept that helps children build good habits and basic money awareness through daily tasks and coin rewards.

## Prototype included

This repository now includes a complete visual identity + key screen prototype with:

- Pastel palette (mint, lavender, peach, lemon) and rounded UI
- Friendly mascot-style blob characters across screens
- Onboarding purpose selection
- Coin dashboard
- Daily + one-time task lists
- Progress tracking
- Completion celebration overlay
- Reward redemption flow
- Icon-only bottom navigation

Design Inspiration: https://dribbble.com/shots/27139208-Kids-Educational-App-Branding

## Run locally

Open `index.html` in a browser, or serve the directory:

```bash
cd kid-coins
python3 -m http.server 8000
```
